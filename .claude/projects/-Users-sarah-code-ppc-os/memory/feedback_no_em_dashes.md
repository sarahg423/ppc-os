---
name: Avoid em-dashes in copy
description: Em-dashes feel inauthentic and AI-generated; use periods, commas, parentheses, or rewrite instead
type: feedback
---

Don't use em-dashes ( — ) in marketing copy, ad text, or any user-facing content. They're a signature of AI-generated writing and feel inauthentic to readers.

**Why:** Sarah called this out when reviewing landing page copy that I'd written with em-dashes throughout. She wanted to keep the brand voice feeling human and direct, not algorithmic.

**How to apply:**
- Replace em-dashes with periods, commas, parentheses, or restructure into two sentences
- This applies to all customer-facing content: ad copy, landing pages, blog posts, email, GBP posts, social
- Internal docs and code comments can still use them
- Watch for variants too (en-dashes, double-hyphens) that read the same way
