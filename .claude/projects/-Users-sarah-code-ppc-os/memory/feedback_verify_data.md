---
name: Always verify external data before using in ads
description: Never use phone numbers, addresses, or business details scraped from search results without confirming with the user first
type: feedback
---

Never use phone numbers, addresses, URLs, or business details pulled from web searches without explicitly confirming them with the user first.

**Why:** During ad extensions setup, a competitor's phone number (Paramount Bristol's) was accidentally used as BRCC's call extension. This could have sent real customers to a competitor.

**How to apply:** When adding contact info, location data, or any business-specific details to ads or config, always ask the user to confirm the value — even if it looks right from a search result.
